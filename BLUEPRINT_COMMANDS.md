## 6. Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + C` | Copy selected text / stop running terminal process |
| `Ctrl + V` | Paste |
| `Ctrl + X` | Cut selected text |
| `Ctrl + A` | Select all |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + S` | Save |
| `Ctrl + F` | Find |
| `Ctrl + H` | Find and replace |
| `Ctrl + Shift + P` | VS Code Command Palette |
| ``Ctrl + ` `` | Open/close VS Code terminal |
| `Up Arrow` | Previous terminal command |
| `Down Arrow` | Next terminal command |
| `Tab` | Autocomplete file/folder names |
